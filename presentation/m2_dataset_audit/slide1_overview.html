5 key findings that block distance-matrix quality

  2. Composite-field explosion — 5 smartphone columns each pack 3–5 independent dimensions
  3. Format inconsistency — 48 price rows use Indian numbering ("₹1,14,990"); brand casing mixed
  4. Tractor brand coverage — only Valtra + Massey Ferguson (no competitor benchmark)
  5. Schema mismatch — two Feature_data sheets have different columns ⇒ no unified pipeline
